# Отчёты Яндекс.Директа (read-only)

Скрипт `report.py` читает статистику кампаний через Reports API v5.
Ставки, бюджет и настройки он не меняет.

## Как получить токен

1. Зайдите в аккаунт Яндекса, которому принадлежит кабинет Директа.
2. Откройте `oauth.yandex.ru/client/new` → создайте приложение
   (название любое, платформа «Веб-сервисы», Redirect URI можно оставить
   стандартный `oauth.yandex.ru/verification_code`).
3. В разделе «Доступ к данным» найдите и отметьте **API Яндекс.Директ**.
4. Сохраните приложение — скопируйте **Client ID**.
5. В браузере (с тем же аккаунтом) откройте:
   `oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`
   → разрешите доступ → скопируйте токен со страницы (или из адресной
   строки после `#access_token=`).
6. Токен можно отозвать в любой момент на `id.yandex.ru/security/app-list`.

Токен — как пароль от всего кабинета. Не коммитьте его: `.env*` уже
в `.gitignore` этого репозитория.

## Запуск

```bash
export YANDEX_DIRECT_TOKEN="ваш_токен"
python3 tools/yandex-direct/report.py 2026-08-05 2026-08-07
# с целью из Метрики (если уже настроена):
python3 tools/yandex-direct/report.py 2026-08-05 2026-08-07 telegram_click
```

Выводит TSV: кампания, показы, клики, расход, CTR, средняя цена клика
(и конверсии по цели, если указан GOAL_ID).
