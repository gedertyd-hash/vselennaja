# Экспорт товаров из Ozon Seller API

Отдельный скрипт, не связанный с сайтом «ИИшница» — просто лежит в этом
репозитории для удобства. Выгружает по каждому товару: наименование,
описание, характеристики и контент-рейтинг ("качество" заполнения карточки).

## Как получить ключ

1. Личный кабинет продавца → **Настройки → Seller API**.
2. Создать API-ключ с правами на чтение раздела «Товары и цены»
   (для этого скрипта хватит read-only).
3. Скопировать **Client-Id** и **Api-Key**.

## Запуск (у себя на компьютере)

```bash
cd scripts/ozon-seller
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# открыть .env и вписать туда OZON_CLIENT_ID и OZON_API_KEY
python export_products.py
```

Результат — `products.csv` рядом со скриптом (открывается в Excel/Google Sheets).

## Важно про безопасность

- `.env` уже в `.gitignore` — не попадёт в git. Не вставляйте ключ прямо в
  `export_products.py` и не присылайте его в чат: токен даёт полный доступ
  к магазину, и если он получит правами на запись — злоумышленник сможет
  менять цены и карточки товаров.
- Если ключ всё же где-то засветился — перевыпустите его в кабинете
  (старый сразу перестанет работать).

## Почему я не могу запустить его прямо здесь

Эта сессия работает в изолированной песочнице без доступа к внешним API
(в частности, исходящие запросы на `api-seller.ozon.ru` блокируются
политикой сети). Даже если вставить сюда токен, выполнить запрос к Ozon
из этого чата не получится — скрипт нужно запускать у себя (см. выше)
или на сервере/в облаке с доступом в интернет.

## Если Ozon поменял формат ответа

API Ozon меняется. Если какой-то метод вернёт ошибку или пустые поля —
сверьтесь с актуальной документацией https://docs.ozon.ru/api/seller и
поправьте соответствующую функцию в `export_products.py`.
