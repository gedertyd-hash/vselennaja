# Скрипты Ozon Seller API

Отдельные скрипты, не связанные с сайтом «ИИшница» — просто лежат в этом
репозитории для удобства.

- `export_products.py` — по каждому товару: наименование, описание,
  характеристики и контент-рейтинг ("качество" заполнения карточки).
- `export_analytics.py` — аналитика за месяц: трафик и конверсия по SKU
  (`analytics_traffic.csv`) и отчёт о реализации — факт продаж, комиссии,
  логистика (`analytics_realization.json`).

## Как получить ключ

1. Личный кабинет продавца → **Настройки → Seller API**.
2. Создать API-ключ с правами на чтение разделов «Товары и цены» и
   «Аналитика»/«Финансы» (read-only достаточно для обоих скриптов; запись
   понадобится позже, когда будем заливать SEO в карточки).
3. Скопировать **Client-Id** и **Api-Key**.

## Запуск без терминала — через GitHub

Не нужен ни Python, ни установка чего-либо на компьютер.

1. Убедитесь, что репозиторий **приватный** (Settings → General → Danger
   Zone → Change visibility → Private) — иначе выгруженные товары сможет
   скачать кто угодно.
2. В репозитории: **Settings → Secrets and variables → Actions → New
   repository secret**. Добавьте два секрета: `OZON_CLIENT_ID` и
   `OZON_API_KEY` (значения — из кабинета продавца, см. выше). Один раз
   сохранённый секрет посмотреть снова нельзя, только перезаписать.
3. Вкладка **Actions** → в списке слева нужный workflow:
   - **«Ozon — экспорт товаров»** — просто Run workflow.
   - **«Ozon — аналитика за месяц»** — Run workflow попросит указать год
     и месяц (например `2026` и `7` для июля), впишите и запускайте.
4. Через пару минут запуск позеленеет — откройте его и внизу страницы
   в разделе **Artifacts** скачайте `ozon-products` или `ozon-analytics`.

## Несколько магазинов

Оба workflow принимают поле **store** при запуске (Run workflow → появится
текстовое поле). Пусто — используется основной магазин (секреты
`OZON_CLIENT_ID`/`OZON_API_KEY` без суффикса). Чтобы добавить ещё один
магазин с кодом, например, `KOCHOI`:

1. Добавьте секреты `OZON_CLIENT_ID_KOCHOI` и `OZON_API_KEY_KOCHOI`
   (ключи из кабинета того магазина) — те же шаги, что выше, просто с
   суффиксом в имени.
2. При запуске workflow впишите в поле **store**: `KOCHOI`.

Код магазина — только латиница/цифры/подчёркивание (так требует GitHub
для имён секретов), название магазина может быть любым — просто выберите
код, который сами запомните.

## Запуск (у себя на компьютере)

```bash
cd scripts/ozon-seller
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# открыть .env и вписать туда OZON_CLIENT_ID и OZON_API_KEY
python export_products.py
# или, с параметрами месяца:
ANALYTICS_YEAR=2026 ANALYTICS_MONTH=7 python export_analytics.py
```

Результат — CSV/JSON рядом со скриптом (CSV открывается в Excel/Google Sheets).

## Важно про безопасность

- `.env` уже в `.gitignore` — не попадёт в git. Не вставляйте ключ прямо в
  `export_products.py` и не присылайте его в чат: токен даёт полный доступ
  к магазину, и если он получит правами на запись — злоумышленник сможет
  менять цены и карточки товаров.
- Если ключ всё же где-то засветился — перевыпустите его в кабинете
  (старый сразу перестанет работать).

## Почему я не могу запустить его прямо здесь

Эта сессия работает в изолированной песочнице без доступа к внешним API
(в частности, исходящие запросы на `api-seller.ozon.ru` блокируются
политикой сети). Даже если вставить сюда токен, выполнить запрос к Ozon
из этого чата не получится — скрипт нужно запускать у себя (см. выше)
или на сервере/в облаке с доступом в интернет.

## Если Ozon поменял формат ответа

API Ozon меняется. Если какой-то метод вернёт ошибку или пустые поля —
сверьтесь с актуальной документацией https://docs.ozon.ru/api/seller и
поправьте соответствующую функцию в `export_products.py`.
