# Ozon Performance API (реклама)

Отдельный API от Seller API — отдельные ключи, отдельная авторизация.
Пока только чтение: список кампаний и статистика за период. Управление
ставками/бюджетом (то, что реально тратит деньги) — сознательно не
автоматизировано на этом шаге, разберём отдельно, когда будет видно,
что показывает статистика.

## Как получить ключи

1. Зайти на **performance.ozon.ru** под тем же логином, что и обычный кабинет.
2. **Настройки → API-доступ** (или «Соединение по API» — формулировка могла
   немного отличаться) → создать новый доступ.
3. Скопировать **Client ID** и **Client Secret** — это не те же значения,
   что Client-Id/Api-Key от Seller API, они отдельные.

## Запуск без терминала — через GitHub

Как и с товарами/аналитикой:

1. **Settings → Secrets and variables → Actions → New repository secret**:
   `OZON_PERF_CLIENT_ID` и `OZON_PERF_CLIENT_SECRET`.
2. Вкладка **Actions** → **«Ozon — рекламные кампании»** → **Run workflow**
   → впишите год/месяц для статистики → Run.
3. Artifacts → скачать `ozon-ads` (там `campaigns.csv`, и если получится —
   `campaign_stats.csv`).

## Если статистика не выгрузится с первого раза

Метод асинхронный (Ozon формирует отчёт в фоне), и точный формат ответа я
не проверял на реальных данных. Если увидите `campaign_stats.raw` вместо
`.csv` — это нормально на первый раз, пришлите мне лог запуска (или сам
файл), я поправлю разбор под реальный формат — так же, как было с отчётом
о реализации.
